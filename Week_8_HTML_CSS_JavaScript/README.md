# Week 8 — HTML, CSS, JavaScript

## Overview & Tech Stack

Week 8 covers the Internet, TCP/IP, DNS, HTTP, URLs, HTML tags and attributes, servers, regular expressions, CSS selectors and properties, frameworks, JavaScript, events, and the DOM.

**Tech stack:** HTML5, CSS3, JavaScript, Bootstrap, browser events, DOM queries, and Python's simple local HTTP server.

## Problem Sets Breakdown

- **Trivia** — the lecture practice page attaches JavaScript listeners to multiple-choice buttons and a free-response input. It updates the DOM and changes styles to provide immediate correct/incorrect feedback.
- **Homepage** — the personal site contains a Bootstrap-linked landing page, additional page placeholders, and a stylesheet entry point. The current snapshot is intentionally simple, but its structure demonstrates navigation, external CSS, and responsive framework setup.

## Challenges & Reflections

I initially treated the browser as a passive place where HTML was displayed, but JavaScript made the page feel like a stateful application. The difficult part was not writing a click handler; it was making sure the selector, event, feedback element, and visual state all agreed. I also learned that a polished page depends on small details—semantic structure, spacing, and consistent CSS—not only on whether the interaction technically works.
