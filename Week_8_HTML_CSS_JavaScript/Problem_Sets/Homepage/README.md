# Homepage

## What it does

Homepage is a small personal website built with HTML, CSS, Bootstrap, and multiple linked pages. The current implementation includes a landing page and placeholders for About, Contact, and Hobby pages.

## Use

No compilation is required. Open `index.html` in a browser, or serve the directory locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000/>.
