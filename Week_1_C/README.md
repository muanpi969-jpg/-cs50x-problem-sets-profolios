# Week 1 — C

[Back to the portfolio](../README.md)

Week 1 covers the foundations of C: source and machine code, compilation, types, variables, operators, conditionals, loops, command-line development, integer overflow, and floating-point imprecision.

## Contents

- [Lecture practice](./Lecture_Practice/): introductory programs such as `hello.c`, `meow.c`, comparisons, calculators, and debugging exercises.
- [Problem sets](./Problem_Sets/): Hello, Mario, Cash, and Credit.

See the [official Week 1 page](https://cs50.harvard.edu/x/weeks/1/) for lecture material and the [official Problem Set 1 specification](https://cs50.harvard.edu/x/psets/1/).
