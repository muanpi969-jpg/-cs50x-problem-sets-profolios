# Hello

## What it does

The C program in this folder asks for the user's name and prints a personalized greeting. It represents the introductory “Hello, It's Me” exercise from Problem Set 1.

## Compile

From this directory in a CS50 environment:

```bash
clang helloname.c -o helloname -lcs50
```

## Use

```bash
./helloname
```

Enter a name when prompted.
