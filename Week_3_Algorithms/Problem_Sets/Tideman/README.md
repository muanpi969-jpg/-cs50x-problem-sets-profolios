# Tideman

## What it does

Problem Set 3's Tideman exercise implements ranked-choice voting with pairwise preferences, a graph of locked-in victories, and a method for avoiding cycles.

No Tideman source file was present in the workspace; this directory is retained as a syllabus-aligned placeholder.

## Compile and use

Once a source file is added, compile it in a CS50 environment with `clang tideman.c -o tideman -lcs50`, then run `./tideman candidate1 candidate2 ...`.
