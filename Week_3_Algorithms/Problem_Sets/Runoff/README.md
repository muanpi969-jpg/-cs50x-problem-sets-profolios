# Runoff

## What it does

Problem Set 3's Runoff exercise simulates ranked-choice voting, redistributing votes until a candidate earns a majority or the election reaches a tie.

No Runoff source file was present in the workspace; this directory is retained as a syllabus-aligned placeholder.

## Compile and use

Once a source file is added, compile it in a CS50 environment with `clang runoff.c -o runoff -lcs50`, then run `./runoff candidate1 candidate2 ...`.
