# Plurality

## What it does

Problem Set 3's Plurality exercise implements a simple election in which each voter selects one candidate and the candidate with the most votes wins.

No Plurality source file was present in the workspace; this directory is retained as a syllabus-aligned placeholder.

## Compile and use

Once a source file is added, compile it in a CS50 environment with `clang plurality.c -o plurality -lcs50`, then run `./plurality candidate1 candidate2 ...`.
