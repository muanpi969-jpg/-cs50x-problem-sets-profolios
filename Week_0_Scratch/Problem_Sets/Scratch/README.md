# Scratch

## What it does

Problem Set 0 asks for an original interactive project built in Scratch. It applies events, variables, conditionals, loops, and custom blocks to solve a problem creatively.

No `.sb3` project file was present in the source workspace, so this directory is currently a reserved location.

## Build and use

Scratch projects are opened and run in the [Scratch editor](https://scratch.mit.edu/). Upload the project file, click the green flag, and follow the on-screen interaction.
