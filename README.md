# CS50x Portfolio

This repository is a structured portfolio of my work from Harvard's **CS50x: Introduction to Computer Science**. It includes lecture practice, problem-set implementations, supporting data, and a Flask-based final project.

The repository follows the course sequence published on the [official CS50x syllabus](https://cs50.harvard.edu/x/weeks/). Each unit contains a `Lecture_Practice/` area and a `Problem_Sets/` area so that examples and assessed work remain easy to navigate.

## Working with the code

Most C assignments use the CS50 library and are intended to be compiled in a CS50 development environment. Python and Flask projects include local run instructions in their project-level README files. SQL exercises can be explored with the `sqlite3` command-line client.

Generated binaries, Python caches, local database build artifacts, and operating-system metadata are excluded through [.gitignore](./.gitignore).

## Academic honesty

This repository is presented as a personal learning portfolio. It should be used consistently with [CS50's academic honesty policy](https://cs50.harvard.edu/x/honesty/).
