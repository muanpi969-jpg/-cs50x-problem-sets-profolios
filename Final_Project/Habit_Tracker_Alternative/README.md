#### Description:

Habit Tracker is a simple web application that helps users track daily habits.

Users can add habits and mark them as completed.

This project uses:

- Python (Flask)
- SQLite
- HTML

The main file is app.py which handles logic.
The database stores habits.
The index.html shows the list.

This project demonstrates CRUD functionality using Flask.
